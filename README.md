# TZF VDowloand

**Plugin gratuito para Adobe Premiere Pro 2026**

O **TZF VDowloand** é uma extensão para Adobe Premiere Pro que permite baixar vídeos de diferentes plataformas e converter vídeos em arquivos MP3 diretamente pelo painel do plugin, facilitando o fluxo de trabalho de edição.

## Funcionalidades

- Download de vídeos do YouTube, incluindo Shorts.
- Download de vídeos do Instagram.
- Download de vídeos do TikTok.
- Conversão de vídeos para MP3.
- Importação de arquivos para o projeto do Adobe Premiere Pro.
- Biblioteca de downloads com histórico e miniaturas.
- Separação da biblioteca entre vídeos e áudios.
- Indicador de progresso dos downloads.
- Acesso à pasta dos arquivos baixados.
- Servidor local com inicialização automática no Windows.
- Interface escura com detalhes em vermelho.

## Requisitos

- Windows.
- Adobe Premiere Pro 2026.
- Permissão para instalar programas e plugins no computador.
- Conexão com a internet para realizar downloads.

**Observação:** o plugin foi desenvolvido e testado no Windows com Adobe Premiere Pro 2026. A compatibilidade com outras versões e sistemas operacionais não foi confirmada.

## Instalação

1. Acesse a seção **Releases** deste repositório.
2. Baixe o instalador `TZF-VDowloand-Setup.exe`.
3. Execute o instalador e conclua a instalação.
4. Acesse a pasta de instalação do TZF VDowloand.
5. Abra a pasta `Plugin`.
6. Execute o arquivo `.ccx` e confirme a instalação pelo Adobe Creative Cloud.
7. Abra ou reinicie o Adobe Premiere Pro.
8. No menu **Plug-ins**, abra o painel **TZF VDowloand**.

O servidor local é configurado para iniciar automaticamente com o Windows.

## Como utilizar

1. Abra o painel TZF VDowloand no Premiere Pro.
2. Copie o link de um vídeo compatível.
3. Cole o link no campo de download.
4. Selecione o formato desejado, vídeo ou MP3.
5. Inicie o download e acompanhe o progresso.
6. Acesse os arquivos pela biblioteca do plugin.

## Avisos importantes

O TZF VDowloand é um projeto independente e não possui vínculo oficial com Adobe, YouTube, Instagram ou TikTok.

Utilize o plugin somente para baixar conteúdos que você tenha autorização para acessar, reproduzir e utilizar, respeitando os direitos autorais e os termos das plataformas.

A disponibilidade dos downloads pode variar conforme mudanças realizadas pelas plataformas.
